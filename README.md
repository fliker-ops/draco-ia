# DRACO AI

DRACO es un asistente virtual futurista creado en Python con una interfaz estilo inteligencia artificial usando PyQt5.

Incluye reconocimiento de voz, síntesis de voz, animaciones futuristas y comandos inteligentes para interactuar con el usuario de forma similar a un asistente tipo Jarvis.

## Características

* Interfaz futurista animada
* Reconocimiento de voz
* Respuestas por voz
* Búsquedas en Google
* Apertura de YouTube y páginas web
* Reproducción de música
* Consultas con Wikipedia
* Chat visual estilo IA
* Animaciones en tiempo real con PyQt5

## Tecnologías usadas

* Python
* PyQt5
* SpeechRecognition
* pyttsx3
* Wikipedia API
* PyWhatKit
* YouTube Search Python

## Instalación

```bash
pip install PyQt5 pyttsx3 SpeechRecognition wikipedia pywhatkit requests youtube-search-python pyaudio
```

## Ejecutar

```bash
python draco.py
```

## Comandos de voz

* "abre google"
* "abre youtube"
* "busca tecnología"
* "pon música"
* "qué hora es"
* "salir"

## Objetivo

El objetivo de DRACO es crear un asistente visual moderno y futurista inspirado en inteligencias artificiales de películas y videojuegos.
